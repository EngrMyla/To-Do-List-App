
# To-Do List App

A simple Python-based to-do list application that let users add, view, remove, and mark tasks as complete.

### Features
- Add a new task
- View all tasks
- Remove a task
- Mark a task as completed
- Simple command-line interface

### How to Run
- 1. Open the project folder.
- 2. Make sure that Python is installed on your device.
- 3. Run the following command in PowerShell:
```bash
py main.py
```

### Requirements
- Python 3.x
